说明：数据默认存在本机浏览器 localStorage，电脑与手机各自独立、不会自动同步。百度网盘无法被网页直接读写（浏览器跨域 + 需网盘授权），但可用「导出 JSON → 存百度网盘 → 手机下载 → 导入」的半自动流程跨设备同步；或在上方填「同步 URL + 访问令牌」对接 GitHub 私有仓库（例如 https://api.github.com/repos/你的名/仓库/contents/workbench-state.json）。配置后电脑/手机打开即自动互相同步，无需手动导出导入。

添加到主屏幕（JL 图标）

现在这个页面直接托管在 GitHub Pages 上，自带 JL 手写图标。用浏览器菜单「添加到主屏幕」即可，无需任何入口页。iPhone：Safari「分享 → 添加到主屏幕」；安卓：Chrome/Edge 右上「⋮ → 添加到主屏幕」。

微信内置浏览器没有「添加到主屏幕」，请先用「··· → 在浏览器打开」再操作。添加到主屏后，点图标即全屏打开工作台，与电脑端自动同步。
