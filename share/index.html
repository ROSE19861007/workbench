开始使用 · 四步填好自己的工作台

① 点右上角「＋ 新建」加任务，设日期后会自动进四象限；
② 点下面的分类卡片进去，加自己的分组、事项和网址；分类名字、数量和顺序都能在「设置 → 分类管理」里自己改；
③ 到「设置 → 数据管理 → 清空示例数据」一键清掉示例；
④ 换设备或清浏览器缓存前，务必「导出 JSON 备份」，新设备用「导入恢复」还原。

默认只存在这台设备的这个浏览器里，不会上传。电脑和手机各存各的，靠导出/导入搬运；想自动同步，到「设置 → 多设备自动同步」填一次自己的私有仓即可。

个性化 · 缩写与配色

缩写与配色会存进你的数据，配好同步后手机和电脑会一起变。主屏图标是共用的一张图，想换成自己的缩写请用「下载带我缩写的图标」并替换自己部署目录里的 PNG。

多设备自动同步（可选，不填也能用）

默认只存在这台设备，不上传、不自动同步，电脑和手机各存各的。想跨设备：① 手动「数据管理 → 导出 JSON / 导入恢复」（可存进百度网盘当中转）；② 或在本卡片填自己的私有仓地址与令牌，开启自动同步。

存到手机桌面

用手机浏览器打开工作台网址后：安卓 Chrome / Edge 右上「⋮ → 安装应用 / 添加到主屏幕」；iPhone Safari「分享 → 添加到主屏幕」。 微信里没有这个功能，需先「··· → 在浏览器打开」。桌面图标打开的是同一个网址，数据依旧存在该浏览器里。

⚠️ 清理浏览器数据 / 换手机 / 换浏览器会让内容回到空白模板，记得先导出 JSON 备份。
